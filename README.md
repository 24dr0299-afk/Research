# Research

## Birbhum District Groundwater Nitrate Concentration (2020–2025)

### Study Area
Birbhum District, West Bengal, India (Study area shapefile: `Study_area.shp`)

### Files
- **`Birbhum_Nitrate_Concentration.csv`** — CSV file with columns: Place, Lat, Long, and Nitrate concentration (mg/L) for years 2020–2025 for all 19 Community Development Blocks of Birbhum district.
- **`DATA_SOURCES_AND_REFERENCES.md`** — Comprehensive documentation of all searched research articles, government reports, data portals, and instructions for obtaining the actual measured data.

### Data Status
After an exhaustive search of published research articles, government reports (CGWB, SWID), and open data portals (India WRIS, data.gov.in), **specific block-wise, year-wise nitrate concentration data for Birbhum (2020–2025) is not freely available online**. The CSV contains all 19 block locations with coordinates but nitrate values are marked as NA. See `DATA_SOURCES_AND_REFERENCES.md` for detailed instructions on how to obtain the actual data.

### Key References
1. Nag & Das (2014) — Suri I & II blocks nitrate data (1.5–13.6 mg/L)
2. Thapa et al. (2018) — 109 nitrate sample points with coordinates (Supplementary Table S1)
3. Islam et al. (2025) — 527 samples from Lower Ganga Delta including Birbhum (Springer)
4. CGWB Annual Groundwater Quality Report 2024
5. Mondal (2022) — Review of inorganic pollutants in Birbhum groundwater

### Recommended Data Source
**India WRIS Portal** ([indiawris.gov.in/wris/#/GWQuality](https://indiawris.gov.in/wris/#/GWQuality)) — Select West Bengal → Birbhum → Nitrate → Year to download station-wise data with coordinates.
